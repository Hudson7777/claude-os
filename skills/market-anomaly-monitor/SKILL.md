# 市场异动监控 (Market Anomaly Monitor)

这个 skill 做两件事：**检测价格异动**，然后**归因到具体事件**。核心价值不是告诉你"今天跌了 2%"，而是告诉你"今天跌了 2%，因为 X 事件，市场在 price in Y 预期，后续需要关注 Z"。

---

## 异动判断机制（三层评级）

脚本内置三层评级，从粗到细：

**L1 绝对阈值**（快速粗筛）：单日涨跌幅超过固定阈值

| 类别 | 阈值 |
|------|------|
| 主要指数 (SPY/QQQ/HSI/KOSPI) | ≥ ±2% |
| 个股 (港股/韩股) | ≥ ±5% |
| VIX 恐慌 ETF (UVXY) | ≥ ±15% |
| 原油/黄金 ETF | ≥ ±3% |
| 加密货币 (BTC) | ≥ ±5% |
| 美元指数 ETF | ≥ ±1.5% |

**L2 相对偏离值**（精筛，去除板块联动噪音）：个股涨跌幅 − 基准指数涨跌幅

| 类别 | 基准 | 偏离阈值 |
|------|------|---------|
| 港股个股 | 恒生指数 | ≥ ±4% |
| 韩股个股 | KOSPI | ≥ ±4% |

**综合评级**：

| 评级 | 触发条件 | 含义 |
|------|---------|------|
| 🚨 STRONG | L1 + L2 双触发 | 个股独立异动，非板块联动，需立即归因 |
| ⚠️ MODERATE | 仅 L1 触发 | 绝对幅度大，可能是板块联动，需关注 |
| 👀 WATCH | 仅 L2 触发 | 相对偏离明显，绝对幅度未超阈值，值得留意 |
| ✅ 正常 | 均未触发 | 无需处理 |

## 工作流程（分层触发）

### Step 1：采集价格信号

运行内置脚本（零依赖，纯 Python 内置库）：

```bash
python3 scripts/fetch_prices.py --json-only
```

解析输出 JSON，提取以下字段：
- `has_anomaly`：是否存在 STRONG 或 MODERATE 异动
- `needs_attention`：是否存在 WATCH 信号
- `anomalies.STRONG`：STRONG 异动列表
- `anomalies.MODERATE`：MODERATE 异动列表
- `anomalies.WATCH`：WATCH 信号列表
- `results`：全市场概览数据

### Step 2：分层决策（核心逻辑）

根据 Step 1 的结果，走不同的执行路径：

---

#### 路径 A：无任何异动（`has_anomaly=false` 且 `needs_attention=false`）

**直接输出简短概览，不触发归因搜索，不发送通知。**

输出格式：
```
✅ 市场平稳 [时间]
SPY [涨跌幅] | QQQ [涨跌幅] | BTC [涨跌幅]
HSI [涨跌幅] | KOSPI [涨跌幅] | 黄金 [涨跌幅] | 原油 [涨跌幅]
无异动信号，下次检查继续监控。
```

**流程到此结束。**

---

#### 路径 B：仅有 WATCH 信号（`has_anomaly=false` 且 `needs_attention=true`）

**输出简短提醒，不做完整归因分析。**

1. 整理 WATCH 列表，格式化偏离信息
2. 输出简短 notification 内容，写入报告文件（`/tmp/market-anomaly-{date}.md`），并在对话中展示：

```
👀 市场关注信号 [时间]

以下标的出现相对偏离，绝对幅度未超阈值：
• [标的名] [涨跌幅]，偏离基准 [偏离值]%
• ...

全市场概览：
SPY [涨跌幅] | QQQ [涨跌幅] | BTC [涨跌幅]
HSI [涨跌幅] | KOSPI [涨跌幅]

（相对偏离信号，无需立即行动，持续监控中）
```

**流程到此结束，不触发 Step 3/4 的完整归因。**

---

#### 路径 C：存在 STRONG 或 MODERATE 异动（`has_anomaly=true`）

**触发完整归因分析流程，继续执行 Step 3 和 Step 4。**

优先级：STRONG > MODERATE，先处理 STRONG 异动。

---

### Step 3：搜索触发事件（仅路径 C 执行）

读取 `super-search` skill，对每个 STRONG/MODERATE 异动标的搜索过去 24 小时内的相关新闻。

搜索策略：
1. **宏观政治事件**：搜索 "geopolitical news today"、"Trump announcement today"、"Fed statement today"
2. **针对具体标的**：搜索 "[公司名] news today"、"[行业] sector news"
3. **关联搜索**：
   - 原油异动 → "oil price OPEC Middle East"
   - 科技股异动 → "tech sector AI regulation earnings"
   - VIX 飙升 → "market volatility risk off today"
   - 黄金上涨 → "gold safe haven geopolitical"

搜索时优先使用英文关键词，覆盖 Reuters、Bloomberg、CNBC 等主流财经媒体。

### Step 4：因果归因分析（仅路径 C 执行）

把价格信号和新闻事件放在一起，进行因果推断：

**分析框架**：
- **直接触发**：某个具体事件（声明、数据发布、突发新闻）在时间上与价格变动高度吻合
- **预期修正**：市场在 price in 某个预期，事件改变了这个预期
- **传导效应**：A 市场的变动传导到 B 市场（如美股下跌 → 港股跟跌）
- **不确定性**：找不到明确触发事件，可能是技术性调整或流动性问题

对每个异动，给出：
1. 最可能的触发事件（附新闻来源）
2. 市场逻辑解读（为什么这个事件会导致这个方向的变动）
3. 置信度评估（高/中/低）
4. 后续需要关注的信号

### Step 5：生成完整报告并推送（仅路径 C 执行）

**报告格式**：

```
📊 市场异动监控报告
[日期时间]

━━━━━━━━━━━━━━━━━━━━
🚨 STRONG 异动（需立即关注）
━━━━━━━━━━━━━━━━━━━━

[标的名称] [涨跌幅] [当前价格]
→ 异动原因：[绝对+相对偏离说明]
→ 归因：[事件描述]
→ 逻辑：[为什么这个事件导致这个方向]
→ 置信度：[高/中/低]
→ 来源：[新闻链接]

━━━━━━━━━━━━━━━━━━━━
⚠️ MODERATE 异动（板块联动或独立异动）
━━━━━━━━━━━━━━━━━━━━

[标的名称] [涨跌幅]
→ 异动原因：[绝对阈值触发说明]
→ 归因：[事件描述]
→ 置信度：[高/中/低]

━━━━━━━━━━━━━━━━━━━━
📈 全市场概览
━━━━━━━━━━━━━━━━━━━━

SPY: [涨跌幅] | QQQ: [涨跌幅] | VIX: [涨跌幅]
HSI: [涨跌幅] | KOSPI: [涨跌幅]
BTC: [涨跌幅] | 原油: [涨跌幅] | 黄金: [涨跌幅]

━━━━━━━━━━━━━━━━━━━━
🔭 后续关注
━━━━━━━━━━━━━━━━━━━━

```

**输出方式**：
- 将完整报告写入 `/tmp/market-anomaly-{date}.md`
- 在对话中展示完整报告
- 如果设置了 `ANOMALY_WEBHOOK_URL` 环境变量，同时 POST 报告摘要到 webhook

## 特殊场景处理

### 地缘政治事件
当搜索到涉及战争、停火、制裁、关税等地缘政治新闻时，重点分析：
- 受影响的行业板块（能源、国防、半导体等）
- 避险资产的流向（黄金、美债、美元）
- 与历史类似事件的对比（如"类似 2022 年俄乌冲突初期的市场反应"）

### 美联储/央行动向
当搜索到 Fed 相关新闻时，重点关注：
- 利率预期的变化（CME FedWatch 工具数据）
- 美债收益率的联动
- 成长股 vs 价值股的相对表现

### 财报季
当个股异动与财报相关时，分析：
- 实际 EPS vs 预期 EPS
- 营收 vs 预期
- 指引（Guidance）的变化

## 关于"实时监控"的说明

这个 skill 本身是**单次执行**的。要实现真正的定时监控，需要配合 Claude Code 的 cron 任务（`/loop` 或系统 cron）。

**推荐的自动化设置**：
- 美股交易时段（北京时间 21:30-04:00）：每小时运行一次
- 亚洲交易时段（北京时间 09:30-16:00）：每小时运行一次
- 非交易时段：每 4 小时运行一次（捕捉重大政治事件）

如果用户没有设置自动化，在 skill 执行完毕后，主动询问是否需要帮助设置定时监控。

## 执行注意事项

1. **并行执行**：Step 1 的所有价格查询在脚本内部已并行处理，直接运行脚本即可
2. **容错处理**：如果某个标的价格查询失败（如港股休市），脚本会标记 error，跳过该标的，不中断整个流程
3. **时区意识**：注意各市场的交易时间。港股/韩股在北京时间白天交易，美股在北京时间晚上交易。非交易时段的价格变化反映的是期货/ADR 的预期
4. **避免过度解读**：如果找不到明确的触发事件，诚实说"未找到明确触发事件，可能是技术性调整"，不要强行编造因果关系
5. **分层触发是核心**：绝大多数时候市场平稳，路径 A 直接结束，不消耗搜索配额。只有真正的异动才触发完整分析
